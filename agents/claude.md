# Calyflow website agent notes

## Writing

- Do **not** use em dashes (the Unicode character U+2014). Prefer commas, colons, periods, or parentheses.
  - Bad: `Upload a JD <em-dash> agents do the rest.`
  - Good: `Upload a JD, and agents do the rest.` / `Upload a JD: agents do the rest.`
- Prefer the site’s existing separators where a divider is needed: middot (`·`) in mono footnotes, colon in page titles (`Calyflow: Agentic Recruiting`).
